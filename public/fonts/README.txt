Satoshi (optional)
------------------
The design uses Satoshi for body text. It is not distributed on npm, so the
project falls back to DM Sans, which is very close.

To use the real font:
1. Download Satoshi from https://www.fontshare.com/fonts/satoshi
2. Copy Satoshi-Regular.woff2 and Satoshi-Medium.woff2 into this folder.
3. Uncomment the @font-face block at the top of app/globals.css.
